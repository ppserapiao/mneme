# Code of Conduct

The mneme project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text is available at the link above.

In short: we expect everyone participating in the mneme community — issues, pull requests, discussions, code review, social channels — to be respectful, constructive, and honest. Harassment, personal attacks, and discriminatory behaviour are not tolerated.

## Scope

This code applies to all project spaces — the GitHub repository (`github.com/ppserapiao/mneme`), public discussions, documentation, the Mneme website, and any official off-platform channels (Discord, X, etc.) — and to anyone acting as a representative of the project.

## Reporting

If you witness or experience unacceptable behaviour, please report it privately to **conduct@mneme.dev** (or, until that mailbox is provisioned, to **ptengelmann@gmail.com** with subject line `mneme conduct`).

Reports are read by the project maintainer and treated as confidential. We will acknowledge within **2 business days** and take action proportionate to the situation — which may include a private warning, a temporary restriction from project spaces, or a permanent ban for repeat or severe violations.

If your report concerns the project maintainer, please email the same address and indicate that — we will arrange an independent third-party reviewer.

## Enforcement

Maintainers are responsible for clarifying and enforcing this code. Decisions are final but may be appealed once in writing to the same email address. Appeals are reviewed within 14 days.

---

For the full enforcement ladder, definitions of unacceptable behaviour, and the attribution required by the Contributor Covenant, see the [official text](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
